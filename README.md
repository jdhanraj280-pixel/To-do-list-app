# 📝 To-Do List App

A simple and elegant **Flutter To-Do List App** that helps users manage their daily tasks efficiently.  
Add tasks, mark them as complete (✅), or delete them when done.  
Designed with a warm, modern color palette for a pleasant user experience.

---

## 🌟 Features

- ➕ Add new tasks easily  
- ✅ Mark tasks as completed using checkboxes  
- ❌ Delete tasks when no longer needed  
- 🎨 Beautiful UI with custom colors  
- 💾 Lightweight and fast

---

| Purpose | Color | Hex |

| Text/Icons | Dark Maroon | `#662222` |

---

## 🧩 How It Works

1. Type a task name in the text field.  
2. Press **Add** to save the task.  
3. Check ✅ when a task is complete (strikethrough appears).  
4. Tap 🗑️ to delete any task.
